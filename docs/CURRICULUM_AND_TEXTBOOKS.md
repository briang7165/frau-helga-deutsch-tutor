# Curriculum and private learning-library inventory
The learner's OneDrive contains German textbooks. These resources are PRIVATE and are NOT part of this public repository. They can inform broad topic sequencing, but Codex must produce original lessons.

Reference subjects confirmed during planning:
- “Basic German: A Grammar and Workbook” (Schenke/Miell/Seago): foundational case system and grammar units.
- “German Grammar Drills” (Ed Swick): noun gender, plurals, nominative, accusative, dative, prepositions and verb tenses.
- “Deutsche Welle Interaktiv Lehr- und Wörterbuch” A1/A2/B1: multi-level curriculum progression.
- “501 German Verbs” (Strutz): verb conjugation reference.

Start with an A2 diagnostic or warm-up, then lessons can cover articles and cases, verb position in main/subordinate clauses, modal verbs, separable-prefix verbs, Perfekt, common travel and family conversation, comprehension and listening.

Store topic IDs and original examples; track per-topic mastery and intervals rather than using vague “easy/hard” feedback. Decrease mastery when mistakes recur, choose short re-teaching examples, and revisit spaced items. Self-assessed level is not a certificate.

Copyright: never commit PDFs, EPUB files, extracted book text, copied exercises, illustrations, answer keys or private OneDrive paths. Use freely stated grammar rules and original examples.
